# toggle-agents

プラットフォームに依存しないエージェント定義のGit正本です。
SA・Buzz・Codexなどの入口は、ここで管理する同じ定義から配置された本体を呼び出します。

## 役割の分離

- **このリポジトリ**：エージェントの指示、ツール宣言、スキル宣言、合成テストを管理する。
- **agentize-kit**：別管理の開発・検証・ビルド・デプロイ用ツール。実エージェントの正本ではない。
- **実行基盤**：Git定義から生成・配置した版を実行する。
- **チャットの入口**：本人確認、名前指定、会話の入出力、元の会話への配送を担当する。

チャットサービスの管理画面で指示を別々に編集しません。
接続先・実行ID・社員ID・資格情報・本人承認の記録は、公開定義の外で管理します。

## エージェント

| 定義 | 内容 | このリポジトリでの状態 |
|---|---|---|
| [portable_qa](agents/portable_qa/) | 計算・短文作成・架空の質問による共通入口の確認 | 定義を収録。新しい正本と稼働版の再照合は未実施 |
| [expense_assistant](agents/expense_assistant/) | 経費相談・明細プレビューのための共通業務契約 | 移植準備中。業務ツール・本人認証は未接続 |

経費アシスタントは既存実装の完全移植ではありません。名前やプロンプトの追加だけで
カレンダー参照・運賃検索・MF明細登録が使えるようになったとは扱いません。
SA・Buzz・Codexの全てで `@` 呼び出しが稼働済み、という意味でもありません。

## 定義形式

各 `agents/<slug>/` はagentize-kitの基本形式を使います。

- `agent.json`：表示名、説明、記憶・接続などの宣言
- `instructions.md`：プラットフォーム非依存の指示
- `tools.json` / `skills.json`：使う能力の宣言
- `qa.json`：架空の入力例と期待結果（実LLMの評価成功を意味しない）

現在の両定義はツール・スキル・外部接続・永続メモリが無効です。
実行基盤が提供する完了システム操作は業務ツールとは区別します。

## 公開するもの・しないもの

このリポジトリは公開です。汎用の定義と架空のテストだけを収録します。
APIキー、OAuthトークン、非公開カレンダーURL、社内資料・社内固有の規則、個人の経費、
実行ログ、内部環境の配置情報は収録しません。他のprivateリポジトリの履歴も移しません。
未接続の機能を、既定の本番接続や架空の成功結果で補いません。

## 検証

Python 3.11以上、追加依存なしで定義の構造・境界を検査できます。

```sh
python3 -m unittest discover -s tests -v
```

これは定義の検査です。ビルド互換性、実LLM評価、デプロイ、本人認証、各入口の実機往復は
別の検証として記録します。CIは秘密を使わず、外部業務サービスも呼びません。

今後は接続側をこの正本へ切り替え、Gitコミット・定義ダイジェスト・配置版・実行結果を
照合します。既存の稼働設定を、このリポジトリ作成だけで変更することはありません。
